🛑 INTERNET NOT WORKING? START HERE

Post next to the gateway. Don't rely on a phone to find this — if this is the problem, looking things up is what stopped working.

Does this apply?

  • Wi-Fi says connected, full bars — but nothing loads
  • Sites hang, then “can’t find the server” / “no internet connection”
  • Some apps keep working a few minutes, then stop
  • Everyone in the house is affected at once
If Wi-Fi itself is down, or the gateway lights are off or red, this is not it — that’s an ordinary outage. Call the provider.

⚡ TRY THIS FIRST — 30 seconds

A small Raspberry Pi (clear/black box, network cable to the router) handles name lookups for the house.

  1. Is its power light on? If not — unplug power, wait 10 seconds, plug back in.
  2. Wait 90 seconds for it to start.
  3. Try a website again. If this fixes it, you’re done.

THE FIX — under 60 seconds

  1. Open a browser on any device still on the Wi-Fi and go to:
    192.168.1.254
    (Password is on the sticker on the gateway, unless changed.)
  2. Find the page named Home Network, LAN, DHCP, or IP Allocation.
  3. Find the DNS server fields. They currently show 192.168.1.113. Change to Automatic / Obtain from provider / Default.
    No automatic option? Enter these instead:
    Primary 1.1.1.1    Secondary 8.8.8.8
  4. Save. Then turn each device’s Wi-Fi off and on (or restart it) so it picks up the change. Internet should work within a minute.

⚠️ This turns OFF all parental controls

YouTube limits, blocking, and safe search stop for every device. That’s fine — a working internet with no filtering beats a filtered internet that doesn’t work. Tell Garrett; it takes a minute to turn back on.
